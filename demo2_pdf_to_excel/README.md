# Extract invoice data from PDFs into Excel

A sample Python automation: reads PDF invoices and writes one Excel file with an `Invoices` sheet
(vendor, number, dates, subtotal, VAT, total) and a `Line Items` sheet (description, qty, price, amount).
All invoices here are **fake sample documents** generated by `make_sample_invoices.py`.

## Built-in check
For every invoice the script adds up the line items and compares them with the subtotal.
If they do not match, the invoice is flagged `REVIEW` instead of silently trusting the extraction.

## Limits (honest note)
This demo reads text-based PDFs with a consistent layout. Scanned images need OCR first, and very
different invoice layouts need a small adjustment to the patterns in `extract_invoices.py`.

## Run
```
pip install -r requirements.txt
python make_sample_invoices.py    # creates input/ (sample PDFs)
python extract_invoices.py        # writes output/invoices.xlsx
python extract_invoices.py my_folder my_file.xlsx   # use your own PDFs
```
