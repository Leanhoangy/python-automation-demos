# Merge messy Excel/CSV files into one clean report

A sample Python automation: five branch sales files (xlsx + csv) with different column names,
date formats, text prices, duplicates and missing values are merged into one clean Excel report.
All data in this demo is **fake sample data** generated by `make_sample_data.py`.

## What the script handles
- Different header names (`Date` / `Ngay` / `date`) mapped to one schema
- Header row not on the first row (title row above the table)
- Mixed date formats (`2026-08-01`, `01/08/2026`, `08-01-2026`)
- Prices stored as text (`$1,299.50`)
- Spelling/case/space variants (`USB-C HUB`, ` usb-c hub `)
- Duplicate rows removed; rows with missing key values dropped and counted
- Output: `By Branch`, `By Product`, `By Month` summaries + the full clean `All Sales` sheet

## Run
```
pip install -r requirements.txt
python make_sample_data.py      # creates input/ (sample data)
python merge_sales.py           # writes output/sales_report.xlsx
python merge_sales.py my_folder my_report.xlsx   # use your own files
```
